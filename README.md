# DOMEA — aperçu public

Adaptation statique HTML/CSS de l’écran d’accueil DOMEA, à partir du logo vectoriel, des textes, des couleurs et des dimensions de l’interface existante. Ce dépôt ne contient pas l’export complet de l’application Expo.

Les boutons **Se connecter** et **Créer un compte** ouvrent uniquement un message d’information. Aucun identifiant n’est demandé. Cet aperçu ne contient aucun compte, donnée utilisateur, document métier, sauvegarde, secret, service backend ou historique du projet privé.

Le mode clair/sombre suit les préférences du téléphone ou de l’ordinateur. La police Manrope est chargée depuis Google Fonts ; une police système prend le relais si ce service n’est pas disponible. Aucun fichier de police n’est copié dans ce dépôt. Il n’y a ni API, ni traceur, ni cookie, ni stockage applicatif, ni service worker.

## Publication GitHub Pages

Dans ce dépôt : **Settings → Pages → Deploy from a branch → main → /(root) → Save**.

Le fichier `.nojekyll` désactive Jekyll. Les chemins sont prévus pour `/DOMEA-apercu/`. Utiliser l’adresse confirmée par GitHub après une publication réussie.

## Périmètre

Cette présentation ne permet pas d’utiliser DOMEA avec des comptes réels. Le projet complet et ses sauvegardes demeurent séparés dans le dépôt privé ; aucun historique privé n’est importé ici.
